# 三方登录接入方案（微信 / QQ / 抖音）

## 一、需要准备的材料

| 平台 | 注册地址 | 必备材料 | 审核周期 | 年费 |
| --- | --- | --- | --- | --- |
| 微信开放平台 | open.weixin.qq.com | 企业营业执照 + 对公账户 + 300 元认证费 | 1-7 工作日 | 300 元 |
| QQ 互联 | connect.qq.com | 个人/企业实名认证 | 1-3 工作日 | 免费 |
| 抖音开放平台 | developer.open-douyin.com | 个人或企业开发者认证 | 1-5 工作日 | 免费 |

三者在审核通过后都会提供一对 **AppID + AppSecret**，用于 OAuth 2.0 授权码模式。

## 二、OAuth 2.0 授权码流程（三平台一致）

```
用户点击三方按钮
  → 客户端拉起三方授权页（SDK 或浏览器跳转）
  → 用户同意授权
  → 三方回调 redirect_uri 并附带 authorization_code
  → 客户端将 code 发给我方服务端
  → 服务端拿 code + AppSecret 向三方服务器换 access_token
  → 服务端用 access_token 获取用户信息（openid / 昵称 / 头像）
  → 服务端查询 binding 表：openid 已绑定 → 直登；未绑定 → 创建新用户并绑定
  → 服务端签发自有 Sa-Token → 客户端正常使用
```

## 三、服务端设计

### 3.1 新增表：gf_app_user_binding
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint PK | |
| user_id | bigint | 关联的 App 用户 ID |
| provider | varchar(20) | wechat / qq / douyin |
| openid | varchar(128) | 三方唯一标识 |
| unionid | varchar(128) | 微信跨应用 unionid（可空） |
| nickname | varchar(100) | 三方昵称 |
| avatar | varchar(500) | 三方头像 URL |
| UNIQUE(provider, openid, deleted) | | |

### 3.2 新增端点
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /app/auth/oauth/{provider}/url | 获取三方授权跳转 URL |
| POST | /app/auth/oauth/{provider}/callback | 三方回调(code 换 token + 登录/注册) |
| POST | /app/auth/oauth/{provider}/bind | 已登录用户绑定三方账号 |
| DELETE | /app/auth/oauth/{provider}/bind | 解绑 |

### 3.3 服务端实现框架（已落地）
`com.guardfind.server.app.oauth` 包：
- `OAuthProvider` 接口：`authorizationUrl()` / `exchangeToken()` / `fetchUserInfo()`
- `WeChatOAuthProvider` / `QQOAuthProvider` / `DouyinOAuthProvider` 三个实现（需配置 AppID/Secret 后生效）
- `OAuthBindingService`：binding 表 CRUD + 用户创建/关联逻辑
- `OAuthConfig`：按 provider 读取 guardfind.oauth.{provider}.app-id / app-secret 配置

## 四、客户端设计

### 4.1 登录页重设计
参考 market 标准三段式布局：
1. 品牌区（Logo + 标语）
2. 表单区（手机号 + 验证码 + 登录按钮）
3. 三方登录区（微信 / QQ / 抖音三个圆标按钮 + 分割线 "其他登录方式"）

### 4.2 交互状态
| 状态 | 行为 |
| --- | --- |
| AppID 已配置 | 点击按钮 → 拉起授权页 → 回调 → 自动登录 |
| AppID 未配置 | 按钮置灰 + 点击弹 Toast "该登录方式即将开放" |
| 用户拒绝授权 | 返回登录页,不报错 |
| 网络错误 | Toast 提示重试 |

## 五、配置清单（接入时逐项填写）

```yaml
# application-dev.yml 新增
guardfind:
  oauth:
    wechat:
      app-id: ${WECHAT_APP_ID:}
      app-secret: ${WECHAT_APP_SECRET:}
    qq:
      app-id: ${QQ_APP_ID:}
      app-secret: ${QQ_APP_SECRET:}
    douyin:
      app-id: ${DOUYIN_APP_ID:}
      app-secret: ${DOUYIN_APP_SECRET:}
```
